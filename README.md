# MenuBasedProject
Multi-Tool Dashboard is a Streamlit-based platform that unifies Linux SSH management, Gemini AI, AWS cloud services, Git operations, machine learning, automation tools, image processing, and voice control. It helps students, developers, and administrators perform multiple technical tasks efficiently from a single interactive dashboard.
